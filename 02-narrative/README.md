# 02 — Academic Narrative Bank

目标：积累可迁移的论证结构，提高英文写作与研究表达能力。重点是句子承担的功能，不是堆砌复杂词汇。

## Narrative Bank

## Extraction Categories

### Positioning

作者如何说明研究位于哪个领域、回应哪类问题。

### Bottleneck

作者如何准确描述现有方法的不足，避免夸大。

### Causality

作者如何连接原因、机制和结果。

### Contrast

作者如何比较方法、证据或观点。

### Limitation

作者如何限定结论的适用范围。

### Contribution

作者如何把具体工作提升为清晰的学术贡献。

## Reuse Rules

- 记录“逻辑骨架”，不整段复制。
- 保留必要出处，避免日后误当成自己的原创表达。
- 改写时必须匹配新的证据与语境。
- 优先积累清晰、精确、可解释的句式。
- 任何语料都不能代替实际论证。
