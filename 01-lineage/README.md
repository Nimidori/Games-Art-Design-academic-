# 01 — Academic Lineage

目标：把文献放进一条进化链，而不是作为孤立观点阅读。

## Lineage Questions

每篇文献至少回答：

- 它继承了哪些问题、概念或方法？
- 前一阶段的核心瓶颈是什么？
- 作者改变了哪个关键环节？
- 改变带来了什么收益与代价？
- 后续工作最可能从哪里继续？
- 这一变化与游戏艺术或设计实践有什么关系？
