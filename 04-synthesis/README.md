## Opportunity Test

一个候选创新点进入项目之前，应满足：

- [ ] 能指出它来自哪条研究链或实现鸿沟
- [ ] 不只是“换数据集、换美术风格或换平台”
- [ ] 能写成明确的研究问题
- [ ] 有可观察或可测量的结果
- [ ] 在现有时间、技能和设备条件下可完成
- [ ] 对游戏艺术与设计实践具有真实意义
